# ikram_portpolio

## Admin Panel

The portfolio admin is available at `/admin` on the deployed website:

- https://ikram-portpolio.web.app/admin
- https://ikram-portpolio.firebaseapp.com/admin

Before the first sign-in:

1. Open Firebase Console → Authentication → Sign-in method.
2. Enable **Email/Password** authentication.
3. Open `https://ikram-portpolio.web.app/admin`.
4. Select **Create account for the first time**.
5. Enter the configured admin password.

Only `ikramyaseenbaloch64@gmail.com` is authorized by the deployed Firestore rules.
